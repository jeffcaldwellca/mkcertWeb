install guide

  • macOS double-click the downloaded file, add it to Keychain, set trust to "Always Trust"
  • Linux sudo cp rootCA.pem /usr/local/share/ca-certificates/mkcert-rootCA.crt && sudo update-ca-certificates
  • Windows double-click the file, install it to "Trusted Root Certification Authorities"

$ root-ca

installs into the trust store of the machine running this server
